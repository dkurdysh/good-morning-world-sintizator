## Использование ИИ в разработке

При разработке веб-синтезатора **Good morning, world!** использовался ChatGPT (OpenAI) в качестве инструмента для генерации кода и технической поддержки.

Концепция инструмента, визуальный дизайн и структура интерфейса были разработаны автором проекта. ChatGPT использовался для преобразования готового макета в работающий веб-инструмент, реализации звуковой логики на Tone.js, настройки параметров синтезаторов и помощи с публикацией на GitHub Pages.

### Основной промпт для генерации

Ниже представлена структурированная версия основного запроса, использованного при создании проекта.

> Создай интерактивный веб-синтезатор **Good morning, world!** на React, JavaScript и Tone.js.
>
> Используй прикреплённый визуальный макет как основной референс. Интерфейс должен максимально точно соответствовать макету по композиции, типографике, цветам, размерам и расположению элементов.
>
> **Структура инструмента:**
> - Два независимых синтезатора: Synth 1 (Lead) и Synth 2 (Bass).
> - Общая кнопка Power для запуска и остановки воспроизведения.
> - Для каждого синтезатора пять параметров: Volume, Portamento, Type, Detune и Phase.
> - Четыре типа звуковой волны: sine, square, sawtooth и triangle.
> - Независимые аудиоканалы и цепочки звуковых эффектов для двух голосов.
>
> При нажатии Power должна запускаться заранее запрограммированная музыкальная последовательность. Пользователь должен иметь возможность изменять параметры обоих синтезаторов в реальном времени.
>
> Используй React для интерфейса, Tone.js и Web Audio API для синтеза и обработки звука, CSS для стилизации. Организуй проект так, чтобы его можно было открыть в VS Code, дорабатывать и публиковать через GitHub.

**Роль автора:** разработка концепции, создание визуального макета, определение функциональных требований, тестирование результата и принятие решений о доработках.

**Роль ChatGPT:** генерация программного кода, реализация музыкальной логики, технические объяснения и сопровождение процесса разработки.
